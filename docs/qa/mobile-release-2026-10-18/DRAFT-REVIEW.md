## Conditional blockers if these drafts are selected

1. **#370 privacy (Blocker):** `src/lib/sharing/sharedWalks.server.ts` validates eligible stop slugs on create but persists `toPublicWalk(input).route` and returns that route on GET. Its diff does not replace arbitrary sender start/finish coordinates with published landmarks or re-check current publication on public read. `toPublicWalk` is structural projection, not proof that coordinates are public landmarks. Do not ship #370 alone. #373 adds `canonicalShareRoute` on both create/read to remove private GPS and revalidate published eligible stops; that later protection must be retained and integration-tested, including legacy persisted JSON and unpublication.
2. **#370/#373 resource limits (Critical before public links):** POST calls `request.text()` before checking the 16,000-character limit; this is not a bounded stream/byte read. No rate limiter is present in the reviewed POST/GET route diffs. Bound body reads before allocation and apply server rate/cost controls. Do not infer protection from authentication or opaque UUIDs.
3. **Revocation/retention (Major/Critical depending exposure):** GET checks `revokedAt`, but owner revocation UI/API and expiry acceptance are explicitly incomplete in draft descriptions. A schema column does not give the traveler an operable privacy control. Define deletion/revocation semantics and evidence before enabling public links.
4. **#377 app-link origin mismatch (Critical for the proposed feature):** native Finish creates its URL with `citywalkApi.origin`, while associated domains/Android intent filters remain on `getcitywalk.com`. A workers.dev isolated Preview link therefore cannot establish HTTPS app-first behavior for the production-associated host. Use a separately reviewed isolated link/association strategy; do not point device QA at production to work around this. Test custom-scheme parsing separately from verified HTTPS links and browser fallback.
5. **#377 localization (Major):** new shared-walk copy has EN/DE/FR/AR entries, while launch DA/SV/NL/ES fall back to English. Launch-language catalog checks do not cover this inline object. Move/complete copy before claiming six-language parity for that feature. No FR launch requirement is introduced here.
6. **#365 scope/acceptance:** native Finish action hierarchy and visited list change, but the current aggregate diff also includes Web public-link creation and tests. Split/reconcile those changes before selecting visual polish. Existing unit mocks cannot prove star-radio VoiceOver/TalkBack behavior, large text, real share-sheet/cancel, persistence, or save/navigation correctness.
7. **#373/#377 evidence:** prior parent tests, CI quota failures and mergeability do not validate latest stacked heads. Require exact-SHA unit/DB/Cloudflare/mobile checks, isolated migration/API tests, legacy route order, revocation/unpublication, concurrent replacement confirmation, guest privacy, and iPhone/Android cold/warm link acceptance. #373 conflict must be reconciled without importing unrelated work.
