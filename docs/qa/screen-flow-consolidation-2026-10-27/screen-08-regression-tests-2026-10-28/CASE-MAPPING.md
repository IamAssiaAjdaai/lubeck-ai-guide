## Original specification

The complete Arrange / Act / Assert fields are preserved in [CASE-MAPPING.json](CASE-MAPPING.json), referencing the unchanged [technical specification](../screen-08-technical-contract-2026-10-28/REGRESSION-CASES.md). Names prefixed BASELINE are deliberately partial/current-behavior evidence; they do not silently satisfy missing continuation, identity, day/zone or recovery contracts. Strict-red first-failure messages are in [strict-red-evidence.json](strict-red-evidence.json).

No lease registry, guarded writer, date-intent state machine or new planner callback was implemented in test code. In-memory maps in persistence tests implement only the existing WalkStore I/O seam; all parse/replay/clear/start/planning calls are the real production functions. Presentation doubles expose supplied callbacks only, never invent controller transitions.
